API Reference
=============

The API reference describes every public object of tensap: what it
represents, its parameters, what it returns. It is organised by
sub-package. All the objects listed here can be imported from the
top-level package, for instance ``tensap.FullTensor``, except the
benchmarks of :doc:`poincare_learning`.

For the mathematical concepts, see :doc:`/theory/index`; for examples of
use, see :doc:`/examples/index`.
