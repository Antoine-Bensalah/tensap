## Installation

Install from PyPI:

```bash
pip install tensap
```

or from conda-forge:

```bash
conda config --add channels conda-forge
conda config --set channel_priority strict
conda install tensap
```

At minimum, tensap requires NumPy, SciPy and NetworkX. Some applications also
need scikit-learn or TensorFlow.
