Use cases
=========

A use case starts from a scientific problem and shows how tensap addresses
it, possibly combining and comparing several methods. Where the examples of
the :doc:`/examples/index` isolate one method, a use case follows a whole
study: context, model, strategy, analysis of the results and discussion.

More use cases will follow; the longest examples of the gallery, such as
:doc:`/examples/learning/digits_recognition`, will be rewritten here.
